# 本地知识库使用说明

把你想让 AI 助手优先引用的知识文件（.txt 或 .md）放在这个目录下即可，支持多级子目录。

## 📚 支持的格式
- `.txt` — 纯文本（UTF-8 或 GBK 编码均可）
- `.md` — Markdown

## 🏷️ 建议文件内容
示例主题：
- 标准规范：《湖泊富营养化评价方法》《地表水环境质量标准》等摘要
- 业务资料：本地湖泊历史水质数据、治理案例、特定工程指标
- 内部规则：削减方案的工程约束、特殊计算公式、报告模板
- 术语字典：本地口径的术语翻译、缩写对照表

## ⚙️ 配置项（在 .env 中可覆盖）
| 变量 | 默认 | 说明 |
|------|------|------|
| `KB_ENABLED` | `true` | 是否启用知识库（设 false 可临时关闭） |
| `KB_DIR` | `knowledge_base` | 知识库目录（相对项目根） |
| `KB_CHUNK_SIZE` | `600` | 每块最大字符数 |
| `KB_CHUNK_OVERLAP` | `80` | 相邻块重叠字符 |
| `KB_TOP_K` | `3` | 单问题检索最多取几块 |
| `KB_MIN_SCORE` | `0.12` | 最低相似度阈值，低于则不注入 |

## 🔄 自动重载
修改 / 添加 / 删除知识库文件后，系统每 10 秒自动检查文件修改时间，自动重新索引，无需重启服务。

## 💡 调优建议
1. **文档越小越相关越好**：单个文件放 1~5 页专业内容（几千字），不要把几百页整本书丢进来
2. **段落清晰**：每段讲一个主题，用空行或标题分段
3. **中文术语要完整**：TF-IDF 依赖关键词匹配，专业词汇尽量保留全称（如"综合营养状态指数 TLI"）
4. **阈值调节**：
   - 检索到无关内容 → 提高 `KB_MIN_SCORE`（如 0.18）
   - 检索不到内容 → 降低 `KB_MIN_SCORE`（如 0.08）或增加文档量
